## 四、V2EX 推广帖

标题：[开源] VideoForge — AI视频自动化工作台，5分钟出片

正文：
开源了一个 AI 视频创作工具，解决"选题→脚本→配音→分镜"全流程。

技术亮点：

- AI配音：Edge-TTS + Kokoro-FastAPI 双引擎
- 全部 API 本地运行，数据不出本机

安装：
```bash
git clone https://github.com/yao-wen-jie/VideoForge.git
cd VideoForge
start.bat  # Windows
```
