## 三、课程大纲（10节课）

### 模块一：认知篇（为什么现在必须做 AI 视频）

**第1课｜AI 视频的风口还有多久？**
- 2024-2025 视频行业发生了什么变化
- 为什么"会剪视频"不够了，要"会用 AI 生产视频"
- VideoForge 能帮你省多少时间（真实案例：1人日产10条）

### 模块二：工具篇（VideoForge 从安装到精通）

**第2课｜5分钟装好的 AI 视频工厂**
- Windows / Mac 安装全流程
- API Key 配置（硅基流动免费额度怎么领）
- 界面导览：每个按钮是干嘛的

**第3课｜选题矩阵：3秒出10条爆款选题**
- 四大分类怎么选（情感/职场/科技/生活）
- 什么样的选题自带流量（hook 公式）
- 实战：用选题矩阵做一周内容排期

**第4课｜AI 脚本：30秒出口播稿**
- 黄金五段式结构拆解
- 怎么让 AI 写出"人话"（Prompt 技巧）
- 实战：选一个选题，生成3版脚本对比

**第5课｜AI 配音 + 镜头卡：从文字到成片**
- 11种音色怎么选（不同赛道配不同声音）
- 104张镜头卡怎么用（3类必拍镜头）
- 实战：完成一条完整视频的「脚本→配音→分镜」

**第6课｜素材管理与效率翻倍**
- 视频指纹去重原理
- 素材库的整理方法论
- 批量生产工作流搭建

### 模块三：变现篇（怎么用视频赚钱）

**第7课｜短视频的 6 种变现方式**
- 平台流量分成（抖音中视频/视频号创作者分成）
- 带货佣金（选品逻辑 + 挂车技巧）
- 知识付费（卖课/社群/咨询）
- 商单广告（报价策略 + 接单渠道）
- 账号代运营（怎么找客户）
- 卖工具/模板（卖 Notion 模板、Prompt 库）

**第8课｜从0到1起号：30天行动计划**
- Day 1-7：定位 + 刷对标 + 发第一条
- Day 8-14：日更测试 + 数据复盘
- Day 15-21：找到爆款公式 + 复制
- Day 22-30：接第一个商单/挂第一辆车

**第9课｜爆款拆解：为什么这条视频能火？**
- 用 VideoForge 复刻爆款（选题+脚本+配音拆解）
- 3个真实案例拆解（情感类/知识类/带货类）
- 可复制的方法论总结

**第10课｜从副业到主业：规模化放大**
- 矩阵号打法（1个人怎么管3个号）
- 自动化工作流（VideoForge + 剪映 + 定时发布）
- 团队化路径（什么时候该招人）
